# Security Policy

## Supported versions

| Version | Security fixes |
|:--|:--|
| 2.x (latest) | Yes |
| 1.x | No |

## Reporting a vulnerability

Do not report security issues in public issues or discussions.

Submit a private report on the [GitHub Security page](https://github.com/wyb-070110/anmacgamer/security/advisories/new) or contact [@wyb-070110](https://github.com/wyb-070110) privately. Include:

- Affected version and component (Mac app, phone server, Companion app, extension host, or MCP server). Report third-party extension issues to their own repositories.
- Steps to reproduce and expected impact.

We acknowledge reports within 7 days and credit reporters in release notes unless you prefer to stay anonymous.

## 安全策略（简体中文）

请勿在公开 Issue 或讨论区报告安全漏洞。请通过 [GitHub Security 页面](https://github.com/wyb-070110/anmacgamer/security/advisories/new)私下提交，或私下联系 [@wyb-070110](https://github.com/wyb-070110)，写明受影响版本与组件（第三方扩展请报给其各自仓库）、复现步骤和影响。我们会在 7 天内确认，并在修复发布时致谢（不愿署名除外）。
