# Security Policy

## Supported versions

| Version | Security fixes |
|:--|:--|
| 2.x (latest release) | Yes |
| 1.x | No |

## Reporting a vulnerability

Do not report security issues in public issues or discussions.

Report them privately on the repository's [Security page](https://github.com/wyb-070110/anmacgamer/security/advisories/new) using **Report a vulnerability**, or contact [@wyb-070110](https://github.com/wyb-070110) privately. Include:

- Affected version and component (Mac app, phone server, companion app, extension host, local MCP server, etc.). Report issues in third-party extensions (such as the ESP32 touch box) to their own repositories.
- Steps to reproduce or a proof of concept.
- Expected impact.

Reports are acknowledged within 7 days. Confirmed issues are fixed as quickly as possible and credited in the release notes unless you prefer to stay anonymous.

---

## 安全策略（简体中文）

请勿在公开 Issue 或讨论区报告安全漏洞。请通过仓库的 [Security 页面](https://github.com/wyb-070110/anmacgamer/security/advisories/new)点击“Report a vulnerability”私下提交，或私下联系维护者 [@wyb-070110](https://github.com/wyb-070110)，并写明受影响版本与组件（第三方扩展问题请报给其各自仓库）、复现步骤及可能影响。我们会在 7 天内确认收到并在修复发布时致谢（不愿署名除外）。
