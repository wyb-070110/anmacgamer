# Native guide

English · [简体中文](native.zh-CN.md)

A native extension is a C/C++ dylib (or Windows DLL) targeting [`sdk/include/gamescrcpy_ext.h`](../../sdk/include/gamescrcpy_ext.h) (`GS_EXT_ABI_VERSION` 2, generated by `gs api write sdk`). Use it for direct hardware, per-frame touch processing, or custom devices/transports/media/AI/vision; use [logic](logic.md) for UI and standard APIs.

## Minimal example

```cpp
#include <gamescrcpy_ext.h>
#include <string>

namespace {
const gs_ext_host* g_host = nullptr;

int32_t greet(void*, const gs_ext_value* args, uint32_t, gs_ext_result* result) {
    const std::string text = "Hello, " + std::string(args[0].text, args[0].size) + "!";
    return g_host->set_text(result, GS_EXT_TYPE_STRING, text.data(), text.size());
}

const uint32_t kGreetParams[] = {GS_EXT_TYPE_STRING};
const gs_ext_node kGreet = {sizeof(gs_ext_node), "greet", kGreetParams, 1, GS_EXT_TYPE_STRING, nullptr, &greet};
const gs_ext_contribution kContributions[] = {
    {sizeof(gs_ext_contribution), GS_EXT_KIND_NODE, "greet", &kGreet},
};
const gs_ext_plugin kPlugin = {sizeof(gs_ext_plugin), GS_EXT_ABI_VERSION, nullptr, 1, kContributions};
}

GS_EXT_EXPORT int32_t gs_ext_main(const gs_ext_host* host, const gs_ext_plugin** plugin) {
    if (!host || !plugin || host->abi_version != GS_EXT_ABI_VERSION) return GS_EXT_UNSUPPORTED;
    g_host = host;
    *plugin = &kPlugin;
    return GS_EXT_OK;
}
```

Manifest (`"requires": { "native": "^2.0" }`):

```json
"native": {
  "dylib": "libnative.dylib",
  "nodes": [ { "name": "greet", "params": [ { "name": "name", "type": "string" } ], "returns": "string", "description": "Says hello." } ]
}
```

Logic calls `ext.alice.hello.greet("world")` (id segments in lowerCamelCase, e.g. `alice.lap-timer` -> `ext.alice.lapTimer`).

## Entry point and struct versioning

- Export `gs_ext_main`. Keep `gs_ext_plugin` and all pointed data valid until `unload`. Legacy `gs_ext_entry` (ABI 1) is not loaded; rebuild with `"native": "^2.0"`.
- Structs filled by the extension or holding arrays begin with `uint32_t size = sizeof(...)` for forward/backward compatibility. Fixed array elements (`gs_ext_value`, `gs_ext_contact`, etc.) omit `size`.
- Check optional features with `supports("<feature>")`. Features in 2.1.0 / 2.2.0: `jobs`, `events`, `settings`, `claims`, `job-output`, `app-events`, `input-sources`, `services`, `transports`, `media`, `frame-taps`, `vision-engines`, `devices`.

| `attachment` | `GS_EXT_KIND_ATTACHMENT` | `gs_ext_attachment` | `attachments` |
| `behavior` | `GS_EXT_KIND_BEHAVIOR` | `gs_ext_behavior` | `behaviors` |
| `job` | `GS_EXT_KIND_JOB` | `gs_ext_job` | `jobs` |
| `device-provider` | `GS_EXT_KIND_DEVICE_PROVIDER` | `gs_ext_device_provider` | `deviceProviders` |
| `input-source` | `GS_EXT_KIND_INPUT_SOURCE` | `gs_ext_input_source` | `inputSources` |
| `transport` | `GS_EXT_KIND_TRANSPORT` | `gs_ext_transport` | `transports` |

Speech engines and AI providers compose nodes and jobs in the manifest. Optional `gs_ext_plugin` callbacks: `unload`, `settings_changed`, `claim_wanted`, `on_event`, `device_event` (or `NULL`).

## Host functions

Strings are length-delimited UTF-8 (not NUL-terminated unless noted). Statuses (`gs_ext_status`): `GS_EXT_OK`, `GS_EXT_FAILED`, `GS_EXT_UNSUPPORTED`, `GS_EXT_DENIED`, `GS_EXT_BAD_ARGUMENT`, `GS_EXT_BUSY`.

| Functions | Purpose |
|:--|:--|
| `log`, `now_us`, `supports` | Logging, monotonic microsecond clock, feature check |
| `store_get`, `store_set` | Persistent JSON store (<= 1 MiB total, <= 64 levels) |
| `allowed`, `notify` | Permission check; system notification (needs `notify`) |
| `set_text`, `set_error` | Write node result or error to `gs_ext_result` |
| `job_progress`, `job_log`, `job_finish`, `job_fail`, `job_output` | Job lifecycle and partial output |
| `emit_event`, `events_subscribe` | Emit custom events; subscribe to app events (`on_event`) |
| `setting_get`, `devices_changed` | Read manifest settings; refresh device provider list |
| `claim`, `release`, `input_event`, `call_service` | Hardware claims, custom input events, cross-extension services |
| `transport_changed`, `stream_opened`, `stream_data`, `stream_writable`, `stream_closed` | Transport stream lifecycle |
| `sources_changed`, `video_frame`, `audio_samples`, `stream_ended` | Video/audio capture sources |
| `device_list`, `device_open`, `device_write`, `device_control`, `device_close` | Host-mediated serial/HID/BLE I/O |

## Threads, timing, and process isolation

Each extension runs in its own `gs-exthost` process (inside `Contents/MacOS`) over shared memory. A node hanging > 2 s or a broken channel kills the host; 3 crashes in 1 minute disable the extension (writing `crash.txt` and logs). Test out-of-process with `gs ext test <folder> --hosted` ([Testing](testing.md)).

| Callback / call | Thread & timing rule |
|:--|:--|
| Node `call` / device provider `list` | Serialized per binary; return within 100 ms |
| Touch method `open`/`close`/`frame`/`key`… | Single thread; `frame` is time-critical, return immediately |
| Attachment / behavior callbacks | Time-critical, no blocking; 2 ms budget out-of-process; 3 failures in 10 s disable extension |
| Job `start` | Return immediately; run work on your own thread |
| `settings_changed` / `claim_wanted` | Host thread / answer within 1 s |
| `on_event` / `device_event` | Non-UI thread, ordered; return fast (drops above 256 / 1024 queued) |
| `call_service`, `claim` (`GS_EXT_CLAIM_WAIT`) | Only from job or extension thread (never from host callbacks) |
| `device_list`/`open`/`write`/`control` | Only from extension thread (max 20 s wait; `GS_EXT_UNSUPPORTED` on host threads) |
| Vision engine `run` | Dedicated non-UI thread, 1 frame at a time (5 s logic timeout) |
| `input_event`, `emit_event`, `job_*`, `device_close` | Any thread |

## System nodes, touch methods, attachments, and behaviors

- **Nodes** (`gs_ext_node`): validated `args`, write `result->value` (or `set_text`) and return `GS_EXT_OK`, or `set_error` + `GS_EXT_FAILED` (logic gets `GS-API-062`). Missing `nodes[].permissions` returns `GS-API-063` before calling.
- **Touch methods** (`gs_ext_touch_method`): `open` receives `gs_ext_touch_open` (serial + JSON `{ settings, deviceSettings, phone, device, touchBox }`). `frame` receives normalized picture and natural-phone contacts. `key`, `text`, `mouse`, `gamepad` may be `NULL`. Non-`GS_EXT_OK` falls back to normal touch.
- **Attachments** (`gs_ext_attachment`): `input`, `output`, `wake`; `start` receives params JSON (`@position`, `@unit`) and deterministic RNG seed.
- **Behaviors** (`gs_ext_behavior`): custom keymap component with `input`, `frame` (when `wants_frames == 1`), `wake`.

## Jobs

```cpp
int32_t flashStart(void* context, uint64_t job, const char* args, size_t size);
void flashCancel(void* context, uint64_t job);
const gs_ext_job kFlash = {sizeof(gs_ext_job), "flash", nullptr, &flashStart, &flashCancel};
```

- `start` receives `job` id and JSON `args`; return `GS_EXT_OK` immediately and work on your own thread.
- Report `job_progress` (0..1 or -1, throttled to 20/s), `job_log`, and `job_output` (partial JSON, <= 100/s, check `supports("job-output")`). Finish with **exactly one** `job_finish` (<= 252 KiB matching `returns`) or `job_fail`.
- `cancel` requests stop (still end with `job_fail`/`job_finish`; shutdown waits 3 s). Max 4 concurrent jobs (or manifest `most`; excess -> `GS-API-067`). Logic errors: `GS-API-065` (failed), `GS-API-066` (cancelled).

## Events

`emit_event(context, topic, json)`: `topic` 1–64 bytes `[a-z0-9.-]`, must not start with `device.`, `session.`, `profile.`, `app.`, `orientation.`, `recording.`, `window.`, `extension.`, `settings.`. Payload <= 64 KiB (empty -> `null`). First 100/s per topic deliver immediately; rest coalesce to last. Own logic listens via `events.on("<topic>")`, dependents via `events.on("<ext-id>:<topic>")`.

## Program events

`events_subscribe(context, topic, 1|0)` delivers to `on_event(context, topic, json)` (unknown -> `GS_EXT_UNSUPPORTED`, missing `events.app` -> `GS_EXT_DENIED`):

| Topic | Payload | Permission |
|:--|:--|:--|
| `device.connected`, `device.disconnected` | `{ phone, name }` | `events.app` |
| `session.started`, `session.ended` | `{ phone, name, failed? }` | `events.app` |
| `profile.applied` | `{ phone, name, profile, profileName }` | `events.app` |
| `app.foreground` | `{ phone, name, package, game }` | `events.app` |
| `orientation.changed` | `{ phone, name, rotation }` (quarter turns) | `events.app` |
| `recording.started`, `recording.ended` | `{ phone, name, path, durationMs? }` | `events.app` |
| `window.focused` | `{ phone, name, window: "mirror"\|"grid", focused }` | `events.app` |
| `extension.enabled`, `extension.disabled` | `{ id, name, version }` | — |
| `settings.changed` | `{ keys, values, extension, device }` (own + language/theme) | — |

## Settings

`setting_get(context, key, phone, value)` returns JSON valid until next call on same thread (empty `phone` = global; undeclared key -> `GS_EXT_BAD_ARGUMENT`). `settings_changed` receives a JSON array of actually changed keys.

## Device providers

`gs_ext_device_provider { size, name, context, list, act }` (needs `devices.provide`). `list` writes <= 64 JSON items via `set_text`: `{ id*, name* (<= 64 B), kind ("touchBox"), summary (<= 200 B), state (ready|busy|problem|offline), stateText (<= 200 B), icon, touchMethod, resource, capture, actions (<= 8: { id, title, panel?, job? }) }`. Action `id: "settings"` becomes the settings button; others go to More (jobs with string param `device` receive device id; no `panel`/`job` calls `act`). Call `devices_changed(context, provider)` on change.

## Hardware claims

Call `claim(context, resource, flags)` before opening hardware and `release` when done. Case-insensitive names: `serial:/dev/cu.usbserial-0001` (or `serial:COM9` on Windows), `ble:AA:BB:CC:DD:EE:FF`, `hid:<path>`, `usb:<vid>:<pid>:<serial>` (hex). Busy -> `GS_EXT_BUSY`; `GS_EXT_CLAIM_WAIT` asks holder via `claim_wanted(context, resource, by)` (return `GS_EXT_OK` within 1 s and `release` within 3 s to yield). Auto-released on stop. Shared with AOA and `hardware.claim`.

## Input sources

`gs_ext_input_source { size, name }` (needs `input.provide`, manifest `inputSources`). Call `input_event(context, source, slot, x, y, time_us)` from any thread (button `x` 0/1; axis `x` -1..1; stick `x,y` -1..1; `time` 0 = now; max 1000/s per source, return-to-0 always passes). Binds as `Ext.<ext-id>.<source>.<slot>`.

## Services

`call_service(context, "<ext-id>/<service>", args_json, result)` (extension threads only, check `supports("services")`, 10 s timeout). Errors: `GS_EXT_UNSUPPORTED`, `GS_EXT_DENIED` (not in `dependencies`), `GS_EXT_BAD_ARGUMENT` (schema), `GS_EXT_FAILED`. To provide a service via `node`, take 1 `json` param `{ caller, permissions, input }` and return `json` (check `permissions`, not only `allowed()`).

## Speech engines

Manifest `speechEngines` composes jobs/node (id `<ext-id>/<name>`, validated as `speech-engine-invalid`):
- `say` job: params `text` (string), `voice` (string), `rate` (number 0.5–2), `volume` (number 0–1).
- `listen` job: params `phrases` (json array or `null`), `language` (string), `confidence` (number); emit `{ phrase, text, confidence }` via `job_output` until cancelled.
- `voices` node: 0 params -> json `[{ id, name, language }]`.

## Transports

`gs_ext_transport` (needs `transport`, plus `network` if networked; check `supports("transports")`):
- `discover` writes `[{ id, name, model, detail }]` within 100 ms; notify changes via `transport_changed`.
- `open(context, stream, gs_ext_stream_open*)` for `control`, `video`, `audio`, `bulk` returns immediately, then calls `stream_opened` or `stream_closed` within 20 s. Transport launches the phone server and connects to `gs_ext_stream_open.session`.
- `send` <= 64 KiB (`GS_EXT_OK` all taken; `GS_EXT_BUSY` none, wait for `stream_writable`). Inbound bytes use `stream_data`; end with `stream_closed` / `close`.

## Pictures, sound, media outputs, and frame taps

Check `supports("media")` / `supports("frame-taps")`:
- **Video/audio sources** (`gs_ext_video_source`, `gs_ext_audio_source`, `media.capture`): `list`/`open`/`close`, push `video_frame` (`GS_EXT_PIXEL_BGRA` or `GS_EXT_PIXEL_NV12`, 2–4096 px) and `audio_samples` (48 kHz 16-bit/float PCM, 1–8 ch); signal via `sources_changed`/`stream_ended`.
- **Media sinks** (`gs_ext_media_sink`, `media.output`): `open`, `frame` (letterboxed BGRA), `audio`, `close`; copy and return immediately.
- **Recording exporters** (`gs_ext_recording_exporter`, `media.output`): `start(context, job, input_mp4, output_path)` runs as a job (counts toward the 4-job limit).
- **Frame taps** (`gs_ext_frame_tap`, `media.read`): `open` (reopened on resize/rotate), `frame` receives BGRA on dedicated thread (newest waits) and writes up to 256 shapes into `gs_ext_overlay` (`keep = 1` preserves previous shapes).

## Devices through anmacgamer

Needs `hardware` and `supports("devices")`. Host-mediated serial/HID/BLE (same allowlist as `hardware.request`):
- `device_list` -> `[{ id, kind: serial|hid|ble, name, present }]`.
- `device_open(context, id, options, &device, answer)` (serial options `{ baudRate, dataBits, parity, stopBits, flowControl, dtr, rts }`; auto-claims hardware).
- `device_write` (serial <= 65536 B; HID `target: { report }` <= 4096 B; BLE `target: { service, characteristic, response }` <= 512 B).
- `device_control` (`op`: `signals`, `sendFeature`, `getFeature`, `services`, `read`, `subscribe`; base64 bytes).
- `device_close` (any thread, safe in `unload`). Incoming events arrive at `device_event`: `GS_EXT_DEVICE_DATA`, `GS_EXT_DEVICE_REPORT`, `GS_EXT_DEVICE_NOTIFY`, `GS_EXT_DEVICE_CLOSED` (`removed`/`failed`/`forgotten`).

## Recognition engines

`gs_ext_vision_engine { size, name, kinds, context, run }` (max 4 per binary, no permission needed, check `supports("vision-engines")`). `kinds` bitmask (e.g. `1u << GS_EXT_VISION_OCR`) covers manifest `visionEngines[].kinds`. `run` receives read-only BGRA `gs_ext_image` (1–4096 px, `stride >= 4 * width`, alpha 255) and JSON `params`, writes JSON array via `set_text`: `ocr` `{ text, x, y, width, height, confidence }`, `detect` `{ label, x, y, width, height, confidence }`, `classify` `{ label, confidence }` (normalized 0..1). Logic errors: `GS-API-170`..`174`.

## AI providers

Manifest `aiProviders` composes a `models` node and `chat` job (needs `ai.provide`, plus `network` if networked):
- `models` (0 params) -> <= 256 `{ id (<= 256), name?, traits: { think, alwaysThinks, efforts (minimal|low|medium|high|xhigh|max), thinkingEffort, topEffortsThink, longContext, millionContext } }`.
- `chat` (`request` json): `{ model, system, messages, tools, stream, maxTokens, think, effort, longContext }` (`messages` roles: `user` with `text`/`pictures`, `assistant` with `text`/`toolCalls`/`thinkingBlocks`, `tools` with `toolResults`). Requests > ~64 KiB pass `{ "file": "<path>" }` (readable in restricted mode).
- Stream chunks via `job_output` (`{ text }`, `{ thinking }`, `{ toolCall }`); finish with `job_finish` (`{ text, thinking, thinkingBlocks, toolCalls, stop, usage: { input, output } }`, or `{ problem, status, code }`). 2-minute idle timeout. Unavailable provider -> `GS-API-150`.

## Restricted mode

`"sandbox": "restricted"` runs `gs-exthost` under macOS `sandbox_init`:
- Read-only own folder and system libraries; read/write container `~/Library/Application Support/anmacgamer/Containers/GameScrcpy.Extension.<hash>` (also `HOME` and `TMPDIR`); environment limited to `HOME`, `TMPDIR`, `PATH`, and language.
- No network, no child processes, no file writes outside the container, no clipboard/window/settings access.
- Hardware only via [Devices through anmacgamer](#devices-through-anmacgamer) (`hardware` permission; `claim` also needs `hardware`).
- Limits: 200 logs/s, 3 notifications/10 s, 4 device changes/s, 16000 input events/s; events must be valid UTF-8 JSON. (No memory job limit on macOS.)
- `gs ext test` always runs restricted dylibs in `gs-exthost` with the sandbox (`gs-test:<id>`).
- Windows: runs `gs-exthost.exe` in a per-extension AppContainer (`%LOCALAPPDATA%\Packages\GameScrcpy.Extension.<hash>`) with a 1 GiB memory job-object limit.

## Multi-arch and building

- `dylib` accepts a single universal binary (`-arch arm64 -arch x86_64`) or per-arch paths `{ "arm64": "...", "x64": "..." }`. Build with Clang (Xcode Command Line Tools) and export `gs_ext_main` (`GS_EXT_EXPORT` = `__attribute__((visibility("default")))`). Scaffold with `gs ext init native <folder>`.
- Windows: `dll` accepts `{ "x64": "...", "arm64": "..." }` (ignored on macOS; a package may ship both). Build with Visual Studio 2022, link runtime statically (`/MT`), and export `gs_ext_main` (`__declspec(dllexport)`).

## macOS

Use `dylib` in `contributes.native` (single universal path or `{ "arm64": "...", "x64": "..." }`; macOS ignores `dll`, Windows ignores `dylib`, packages can ship both).
- Build with Clang (Xcode CLT), export `gs_ext_main` (`GS_EXT_EXPORT` = `__attribute__((visibility("default")))`).
- `gs validate` inspects Mach-O arch, `gs_ext_main`, and live bound imports (stripping symbols does not hide imports); `task_for_pid`, `mach_vm_write`, `thread_set_state`, `ptrace`, etc. are rejected as injection.
- Runs in `gs-exthost`; crashes write `crash.txt` (signal, address, library, offset) and logs (no minidump).
- `"sandbox": "restricted"` uses macOS `sandbox_init`: read-only own folder and system libs, read/write container `~/Library/Application Support/anmacgamer/Containers/GameScrcpy.Extension.<hash>` (`HOME`/`TMPDIR`), env limited to `HOME`, `TMPDIR`, `PATH`, language; no network or child processes; no 1 GiB Windows job-object limit.

## Errors that logic sees

| Code | Meaning |
|:--|:--|
| `GS-API-060` | Extension is disabled |
| `GS-API-061` | Wrong arg type, missing job arg, or args nested > 64 levels |
| `GS-API-062` | Node failed (`set_error` message) |
| `GS-API-063` | Missing node/job permission |
| `GS-API-064` | Node exceeded 100 ms |
| `GS-API-065` | Job failed (`job_fail` message) or result mismatches `returns` |
| `GS-API-066` | Job cancelled |
| `GS-API-067` | Concurrent job limit reached |
