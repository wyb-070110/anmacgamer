# Writing extensions

English · [简体中文](README.zh-CN.md)

An anmacgamer extension is a folder with a `manifest.json`, packed into a `.gsext` zip file. An extension can provide data (themes, filters, profiles, help), TypeScript logic (in a low-privilege child process), or a native DLL/dylib against a C interface.

| Guide | Covers |
|:--|:--|
| [Manifest reference](manifest.md) | `manifest.json` fields, contributions, `l10n`, and limits |
| [Logic guide](logic.md) | Scripts, UI panels, events, services, network, files, speech, vision, converters, hardware, tours, help |
| [Native guide](native.md) | C interface (`gs_ext_main`), host calls, jobs, events, settings, providers, media, AI, restricted mode |
| [Testing extensions](testing.md) | `gs validate`, `gs check`, `gs ext test`, testing in the app |
| [Packing and publishing](publishing.md) | `gs pack`, signing, `gamescrcpy://` links, update lists, `.gsbundle` |

For exact function signatures, see [sdk/docs](../../sdk/docs/README.md) ([sdk/types](../../sdk/types/gamescrcpy.d.ts)) and [gamescrcpy_ext.h](../../sdk/include/gamescrcpy_ext.h), generated by `gs api write sdk`.

## What an extension can do

Declare every extension point you use in `requires`. You can also export existing profiles, components, or tasks from the app as a starting `.gsext`.

### Data

| Capability | Manifest field | Extension point |
|:--|:--|:--|
| Color theme (dark and light tokens) | `contributes.themes` | `theme` |
| Picture filter (HLSL pixel shader) | `contributes.filters` | `filter` |
| Profiles and profile patches | `contributes.profiles`, `contributes.profilePatches` | `profile` |
| Keymap components (TypeScript) | `contributes.components` | `component` |
| Scheduled or on-demand tasks | `contributes.tasks` | `task` |
| Help articles (Help > Extensions) | `contributes.help` | `help` |
| Guided tours | `contributes.tours` | `tour` |
| Settings (global or per phone) | `settings` | — |
| Translated names and titles | `l10n` | — |
| Interface language pack (optional help) | `contributes.locales` | `locale` |

### Logic

| Capability | Manifest / API | Extension point / permission |
|:--|:--|:--|
| Session (per phone) or app scripts | `contributes.scripts` | `script` |
| Panels, menus, toolbar, status, pages, tray | `contributes.panels` + `ui.*` | `panel` |
| Callable services for other extensions/logic | `contributes.services` + `ext.provide` / `ext.call` | — |
| App and device events | `events.on` | `events.app` (for other phones/windows) |
| HTTPS and WebSocket requests | `net.fetch`, `net.socket` | `network` (with `hosts`) |
| User-picked files and folders | `files.pick`, `files.folder` | `files.pick`, `files.paths` (with `folders`) |
| Local HTTP server on `127.0.0.1` | `net.listen` | `network.listen` |
| Text-to-speech and voice commands | `speech.say`, `speech.listen` | `speech.listen` (for listening) |
| Serial, HID, BLE, custom keymap buttons | `hardware.*`, `input.source` | `hardware` |
| Low-rate mirrored frames | `media.frames` | `media.read` |
| Text/object recognition | `vision.recognize`, `vision.engine` | `device.screen` |
| Profile/task/recording converters | `contributes.converters` | `script` |
| MCP tools for AI clients | `mcp.tool` | — |

### Native

Declared under `contributes.native` with extension point `native`:

| Capability | Field under `contributes.native` | Permission |
|:--|:--|:--|
| Touch methods | `touchMethods` | — |
| System nodes (`ext.<ext>.<node>()`) | `nodes` | per node |
| Component attachments / custom behaviors | `attachments`, `behaviors` | — |
| Cancellable jobs with progress | `jobs` | per job |
| Device providers (Devices page) | `deviceProviders` | `devices.provide` |
| Speech engines (`speech.*`) | `speechEngines` | — |
| Custom input sources (buttons/axes) | `inputSources` | `input.provide` |
| Phone transports (relays, tunnels, cloud) | `transports` | `transport` |
| Video/audio sources | `videoSources`, `audioSources` | `media.capture` |
| Media sinks / recording exporters | `mediaSinks`, `recordingExporters` | `media.output` |
| Full-rate frame taps with overlays | `frameTaps` | `media.read` |
| Recognition engines (`vision.recognize`) | `visionEngines` | — |
| AI providers (Settings > AI, `ai.ask`) | `aiProviders` | `ai.provide` |
| CLI subcommands (`gs ext <ext> <cmd>`) | `contributes.cli` | — |

Native extensions can also store data, notify, emit events, read settings, claim hardware, hear app events, and call services (see [Native guide](native.md)). Set `"sandbox": "restricted"` to run without OS privileges.

## Extension points and versions

`requires` lists each extension point and semver range (for example `"script": "^1.1"`). Minor bumps add features and remain backward-compatible; major bumps break compatibility.

Versions offered by anmacgamer 2.2.0:

| Extension point | Version | Used by |
|:--|:--|:--|
| `theme`, `filter`, `profile`, `help`, `tour`, `locale` | 1.0 | `themes`, `filters`, `profiles`/`profilePatches`, `help`, `tours`, `locales` |
| `component`, `task`, `script`, `panel` | 1.1 | `components`, `tasks`, `scripts`/`converters`, `panels` (also needs `script`) |
| `native` | 2.1 | `contributes.native` |

Reserved (not yet offered in 2.2.0): `command`, `preset` (extensions requiring them install but stay off). Undeclared contributions trigger `contribution-undeclared` in `gs validate`. Incompatible extensions stay off after an app update and appear in a one-time prompt with "Check for updates" and "Open Extensions".

Optional `"gamescrcpy"` records the target app major.minor for display on cards and dialogs; compatibility is still decided by `requires` (see [Manifest reference](manifest.md#which-version-it-was-written-for)).

## Permissions

Extensions start with zero permissions. Declare each needed permission with a `reason` in `permissions` (allowed only when requiring `script`, `component`, `task`, or `native`). Missing permissions fail at runtime (`GS-API-072` in logic, `GS_EXT_DENIED` in native).

| Permission | Prompt text | Grants |
|:--|:--|:--|
| `device.input` | Send touches and keys | `touch.*`, keys, typing |
| `device.screen` | Read the phone screen | `vision.*`, `vision.recognize` |
| `device.clipboard` | Use the phone clipboard | `clipboard.*` |
| `device.apps` | List and open apps | foreground app, launch apps |
| `devices.other` | Control other phones | other phones; optional `maxDevices` (1–64) |
| `mapping` | Trigger controls and switch profiles | `controls`, `mapping.*`, `profile.*`, `globals` |
| `notify` | Show system notifications | `ui.notify`, native `notify` |
| `network` | Use the network | `net.fetch`, `net.socket` (requires `hosts`, allows `*.example.com` and ports); also checked for native network imports |
| `files.pick` | Open files you choose | `files.pick` |
| `files.paths` | Read and write folders you choose for it | `files.folder` (requires `folders`, chosen by user on first use) |
| `input.read` | Read your keyboard and mouse | `input.cursor`, `input.isDown`, key events |
| `hardware` | Access the devices you choose | `hardware.*`, `input.source` |
| `ai` | Use the AI service you set up (it spends your quota) | `ai.ask` |
| `devices.provide` | Add devices to the devices page | native `deviceProviders` |
| `network.listen` | Accept connections from programs on this computer | `net.listen` (toggleable in Details) |
| `speech.listen` | Listen for voice commands you say | `speech.listen` (`speech.say` needs none) |
| `events.app` | Know what happens on every phone and window | cross-phone events for app scripts, tasks, native |
| `input.provide` | Feed the buttons of home-made devices into the key mapping | native `inputSources` |
| `transport` | Provide ways to connect to phones | native `transports` (add `network` if needed) |
| `media.capture` | Provide pictures or sound | native `videoSources`, `audioSources` |
| `media.read` | Read the mirrored picture and sound | `media.frames`, native `frameTaps` |
| `media.output` | Send the picture or the sound elsewhere | native `mediaSinks`, `recordingExporters` |
| `ai.provide` | Provide AI model services | native `aiProviders` (add `network` if needed) |

`adb.shell` is never granted (manifest error). Native binaries are also checked for system imports at install; undeclared network/file/input/process imports are flagged, and process-injection imports are rejected.

## Where the code runs

- Data: no code runs (filter shaders compile on the GPU and are checked by `gs validate`).
- Logic: runs in the low-privilege `gs-scripthost.exe` child process; every API call is permission-checked. `"run": "session"` runs per mirrored phone; `"run": "app"` runs once per app instance. UI is rendered by anmacgamer from a declarative tree.
- Native: each extension runs in its own `gs-exthost.exe` process so crashes stay isolated. `"sandbox": "full"` (default) has user account rights and stricter install checks. `"sandbox": "restricted"` runs in an AppContainer (or macOS sandbox) with no direct file, network, or process access; see [Restricted mode](native.md#restricted-mode).

## Installing, consent and updates

1. Install: use **Install from file…** (`.gsext` or `.gsbundle`) or a `gamescrcpy://install` link ([Packing and publishing](publishing.md)). Packages are checked for manifest, paths, file limits, antimalware (for native), signature, and imports before install.
2. Consent: the extension loads only after the user turns it on and approves its permissions and dependencies.
3. Updates: installing a new version with the same `id` keeps settings and granted permissions. Adding permissions, hosts, folders, or required dependencies pauses the extension ("Turn it on again to allow what's new") until re-approved.
4. Signing: packages can include `SHA512SUMS`, `SHA512SUMS.minisig`, and `authorKey`. First install shows the raw key; later versions with the same key show "Verified publisher". Signed extensions refuse unsigned updates or key changes (reinstall to switch keys).
5. Update checks: extensions with `updates.index` can be checked manually or daily on startup if enabled in Settings > General (off by default). Downloads start only when the user clicks Update and verify size, SHA-256, id, version, and key; see [Update lists](publishing.md#update-lists).

## When something goes wrong

- Check the extension card and Details for manifest, version, dependency, or consent issues.
- An extension is auto-disabled if its process stops 3 times in 1 minute, or if attachments/behaviors fail 3 times in 10 seconds. Re-enabling clears the health alert.
- Logs go to `%APPDATA%\GameScrcpy\logs` (or `data\logs` in portable builds) with prefixes `[extensions] <id>:` and `logic <name> on <phone>:`. **Settings > About > Export diagnostics…** includes extension health and crash reports.
- Use **Find a problem extension** on the Extensions page to bisect, or run `GameScrcpy.exe --safe-mode` (also triggered automatically after a crash with extensions loaded).
