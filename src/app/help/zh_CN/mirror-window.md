投屏窗口会在 Mac 上显示手机画面，并把鼠标、键盘和手柄操作实时传给手机。

![投屏窗口](figure:mirror-overview)

## 直接用键鼠操控

关闭键位映射时，投屏窗口就像一块触控屏：

- 单击即点击，拖拽即滑动，滚轮可滚动页面。
- 键盘打字会直接输入到手机当前焦点中。

开启键位映射后，当前方案的按键会接管操作。详见[方案与分享](help:profiles)和[键位编辑器](help:keymap-editor)。

## 工具栏与自定义按钮

工具栏固定显示**返回**、**主页**和**最近任务**，此外你还可以自选最多 **5 个按钮**（**更多 > 工具栏按钮…**），例如**置顶窗口**。工具栏的显示方式可在**设置 > 投屏与画质 > 显示 > 工具栏**中切换（固定在上方、鼠标悬停顶部显示、或仅快捷键呼出）。

![工具栏](figure:mirror-toolbar)

| 按钮 | 作用 |
|---|---|
| :keyboard: 键位映射与选项 | 开关键位映射、调节提示透明度、切换方案或打开编辑器。 |
| :house: 返回、主页、最近任务 | 手机系统导航键。 |
| :rotate-cw: 方向 | 跟随设备旋转，或锁定竖屏/横屏。 |
| :power: 电源 | 仅熄灭手机物理屏幕，电脑端投屏继续运行。 |
| :volume-2: 音量 | 在 Mac 上静音或调节投屏音量。投屏期间手机自身的音量键不会改变声音大小。 |
| :bot: 任务 | 启停当前手机上的自动化[任务](help:scripts)。 |
| 录制 | 录制视频、声音与操作，可在**更多 > 录制内容…**查看。 |
| :puzzle: 扩展面板 | 打开扩展添加的侧边面板或快捷按钮。 |
| :activity: 诊断信息 | 实时显示帧率、延迟与解码信息。 |
| :maximize-2: 全屏 | 全屏显示画面（按 <kbd>F11</kbd> 进退）。 |
| :ellipsis: 更多 | 状态胶囊模式、**录制内容…**、**编辑逻辑**、**视觉工作台**、**实测延迟**、**置顶小窗**、**置顶窗口**、**设备设置**与**断开连接**。 |
| :pin: 固定 | 让工具栏始终停留在画面上方。 |

## 状态胶囊与键位提示

- **状态胶囊**：右下角显示帧率、延迟和连接方式。左键点击可开关诊断面板；右键点击可设为**自动**、**始终显示**或**隐藏**。
- **键位提示**：开启方案时会在画面上亮起键位提示，随后自动变淡。可在**键位映射选项**或**设置 > 输入与键位**中调整透明度。

## 视角锁定

在射击或动作游戏中，包含**视角**组件的方案可通过视角锁键（默认为 Tab 上方、数字 1 左侧的按键，或方案中指定的按键）隐藏指针，直接移动鼠标转动视角；再按一次恢复指针。

![视角锁定](figure:camera-lock)

如需关闭锁视角时的窗口边缘光晕，可在**设置 > 投屏与画质 > 显示 > 视角锁定时边缘发光**中关闭。

## 在手机上打字

安装[anmacgamer 伴侣](help:companion)后，手机打开输入框时窗口会自动切入打字模式：按 **Enter** 发送，按 **Esc** 回到游戏操控。

## 全屏、小窗与实测延迟

![全屏与小窗模式](figure:window-modes)

- **小窗模式**：点击**更多 > 缩为置顶小窗**，适合挂机或排队时悬浮观看；拖拽可移动，双击或点**恢复**回到正常窗口。
- **实测延迟**：点击**更多 > 实测延迟**，在画面较暗区域点击或按键，系统会统计从触发到画面显示的真实延迟。
- **启动应用**：在**设备**页点击手机卡片的**更多 > 应用**，可在手机上或独立显示窗口中打开应用。

关闭投屏窗口会断开该设备。若在编辑键位时点击关闭，可选择**结束编辑**（保存并保持投屏）或**关闭投屏窗口**。
