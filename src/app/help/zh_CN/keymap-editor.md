键位编辑器用于在手机实时画面上直接为游戏按钮放置并绑定按键。

![键位编辑器](figure:editor-overview)

## 打开编辑器并添加按键

1. **打开编辑器**：在投屏窗口点击工具栏**键位映射选项 > 编辑键位映射**（或新建方案时点击**创建并编辑**）。
2. **挑选组件**：在右侧**组件库**标签页找到需要的组件（可搜索或悬停查看说明）。
3. **放到画面上**：把组件拖到游戏按钮位置，或选中后按 <kbd>Enter</kbd> 放到画面中央。
4. **绑定按键**：按下键盘按键、鼠标键或滚轮即可绑定，点**跳过**可稍后再绑。

![添加按键](figure:editor-components,editor-drag!,editor-capture)

## 内置组件一览

| 分组 | 组件 | 作用 |
|---|---|---|
| 基础 | 点击 | 每次按键轻点一次屏幕。 |
| | 按住 | 按住键期间持续按住屏幕。 |
| | 长按 | 每次按键按住设定的时长。 |
| | 连发 | 按住期间按设定频率连续点击。 |
| | 滑动 | 按绘制的路径滑动一次。 |
| | 捏合 | 两个按键控制双指放大或缩小。 |
| | 多点按住 | 同时按住屏幕上多个位置。 |
| 移动 | WASD 摇杆 | 用 WASD、慢走和冲刺键控制屏幕摇杆。 |
| | 右键行走 | 右键点击画面让角色向该位置移动。 |
| | 手柄摇杆 | 将手柄左摇杆映射到屏幕摇杆。 |
| 轮盘 | 方向轮盘 | 打开游戏轮盘并向指针方向拖动选择。 |
| | 动作轮盘 | 打开自定义轮盘，松开时触发组件、点位或逻辑。 |
| 视角 | 视角 | 锁定视角后移动鼠标转动镜头。 |
| | 手柄视角 | 将手柄右摇杆映射为视角转动。 |
| | 自由视角 | 按住期间移动鼠标环顾四周，不改变朝向。 |
| | 临时指针 | 锁视角期间按住可临时呼出指针点击屏幕。 |
| MOBA | 技能施法 | 按下朝指针方向瞄准，松开或点击释放。 |

系统操作（如返回键、打字、截图、切换方案）在[脚本与逻辑](help:scripts)中调用系统节点完成。

## 示例组件与我的组件

- **示例组件**（**切换按住**、**双击**、**连击**、**轮流点击**、**按住显示全部键位提示**）均由逻辑实现。双击可查看源码，点击**复制到我的组件**即可基于副本修改。
- **我的组件**：点击组件库底部的**新建组件…**，选择起点（空白、内置或已有组件）并编辑逻辑。我的组件跨方案共享，保存后正在投屏的方案会立即热重载。
- **分组与导出**：带有子组件的自定义组件可整组拖入画面；放入自定义组件后，方案会自动转为带逻辑的文件夹方案。

## 排列、编辑与解决冲突

- **选中与移动**：单击选中，<kbd>⌘ Command</kbd>+点击或 <kbd>Shift</kbd>+点击多选，在空白处拖拽框选。拖动时自动对齐其他按键和中心（按住 <kbd>⌥ Option</kbd> 自由摆放），方向键可微调（配合 <kbd>Shift</kbd> 步幅更大）。
- **复制粘贴**：<kbd>⌘ Command</kbd>+<kbd>C</kbd> 复制，<kbd>⌘ Command</kbd>+<kbd>V</kbd> 粘贴到指针处（支持跨设备编辑器粘贴）。
- **定格画面与缩放**：点击**定格画面**可暂停动态画面方便对齐；用工具栏按钮或 <kbd>⌘ Command</kbd>+滚轮缩放，点击百分比重置。
- **属性面板**：选中单个组件可修改按键、灵敏度/时长、**锚点**（适配不同屏幕比例）、**初始启用**、**代码名称**（逻辑中写作 `controls.<name>`）、**生效条件**、扩展**附加效果**以及**在逻辑中使用**。
- **被逻辑接管的按键**：当逻辑监听了组件的按键事件时，键帽右上角会出现逻辑标记，按下时默认只运行逻辑；如需照常先触发点击再跑逻辑，在蓝图事件块中将**按下按键时**设为**照常按屏幕，再运行逻辑**。
- **按键冲突**：两个组件绑定同一按键时，顶栏会显示冲突数，点击即可选中冲突按键并改绑。

![两个按键同时绑定了 Q：顶栏会提示冲突并标红双方按键。](figure:editor-conflict)

- **删除**：按 <kbd>Delete</kbd> 或**更多 > 删除**。若逻辑中引用了该组件，可选择**连同这些块一起删除**、**仅删除组件**（蓝图中失效块可后续替换）或**取消**。

## 试玩、预览与保存

- **试玩**：点击顶栏**试玩**（烧瓶图标）可直接在游戏上测试键位，再点一次回到编辑。
- **预览其他屏幕**：使用**预览屏幕比例**查看 20:9、21:9 等屏幕下的键位排布；编辑前请切回本机比例。
- **画面 / 逻辑**：在顶栏中央切换**画面**与**逻辑**视图。
- **保存**：点击**保存**写入修改，**完成**保存并退出，**更多 > 另存为…**另建方案，或**更多 > 放弃修改并退出**取消。扩展方案可通过**更多 > 恢复原版…**撤销修改。

![试玩期间遮罩消失，所有按键直接作用于实时画面。](figure:editor-try)

## AI 草稿预览

AI 客户端通过 MCP 修改方案后，方案卡片会出现类似**Claude 的草稿**的按钮。打开后进入只读对比视图：绿色为新增、橙色为修改、红色为删除，逻辑与代码差异同步标出。确认无误点**应用**，否则点**放弃**或**关闭**。

## 快捷键

| 按键 | 作用 |
|---|---|
| <kbd>⌘ Command</kbd>+<kbd>Z</kbd> | 撤销 |
| <kbd>⌘ Command</kbd>+<kbd>Y</kbd> | 重做 |
| <kbd>⌘ Command</kbd>+<kbd>S</kbd> | 保存 |
| <kbd>⌘ Command</kbd>+<kbd>D</kbd> | 复制所选按键 |
| <kbd>⌘ Command</kbd>+<kbd>A</kbd> | 全选 |
| <kbd>Delete</kbd> | 删除所选按键 |

可在**设置 > 快捷键速查**中自定义。
